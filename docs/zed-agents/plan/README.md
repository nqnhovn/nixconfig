# Bộ Biểu Mẫu Scrum — Hướng Dẫn Sử Dụng

## Mục đích

Bộ biểu mẫu này cung cấp đầy đủ các tài liệu cần thiết để quản lý dự án phần mềm theo framework **Scrum**. Tất cả biểu mẫu được thiết kế dưới dạng Markdown (`.md`) — bạn chỉ cần mở file và điền trực tiếp thông tin dự án vào các placeholder `[điền tại đây]`.

## Cấu trúc thư mục

```
plan/
├── README.md                         ← File này
├── 01-product-vision.md              ← Tầm nhìn sản phẩm
├── 02-product-backlog.md             ← Product Backlog
├── 03-sprint-backlog.md              ← Sprint Backlog
├── 04-user-story-template.md         ← Mẫu User Story
├── 05-sprint-planning.md             ← Biên bản Sprint Planning
├── 06-daily-standup.md               ← Nhật ký Daily Standup
├── 07-sprint-review.md               ← Biên bản Sprint Review
├── 08-sprint-retrospective.md        ← Biên bản Sprint Retrospective
├── 09-definition-of-done.md          ← Definition of Done (DoD)
├── 10-definition-of-ready.md         ← Definition of Ready (DoR)
├── 11-team-charter.md                ← Team Charter
└── 12-release-plan.md                ← Kế hoạch phát hành
```

## Cách sử dụng

### 1. Khởi tạo dự án

Bắt đầu theo trình tự:

1. **`01-product-vision.md`** — Xác định tầm nhìn sản phẩm và mục tiêu kinh doanh
2. **`11-team-charter.md`** — Thiết lập thỏa thuận nhóm, vai trò, quy tắc làm việc
3. **`09-definition-of-done.md`** — Định nghĩa thế nào là "hoàn thành"
4. **`10-definition-of-ready.md`** — Định nghĩa thế nào là "sẵn sàng" để đưa vào sprint

### 2. Lập kế hoạch

5. **`04-user-story-template.md`** — Dùng mẫu này để viết từng User Story
6. **`02-product-backlog.md`** — Tập hợp tất cả User Story, sắp xếp ưu tiên
7. **`12-release-plan.md`** — Lên kế hoạch phát hành các phiên bản

### 3. Mỗi Sprint

8. **`05-sprint-planning.md`** — Họp lập kế hoạch sprint, chọn story từ backlog
9. **`03-sprint-backlog.md`** — Quản lý tiến độ công việc trong sprint
10. **`06-daily-standup.md`** — Ghi nhận nhật ký standup hàng ngày
11. **`07-sprint-review.md`** — Họp đánh giá kết quả sprint
12. **`08-sprint-retrospective.md`** — Họp cải tiến quy trình

### 4. Liên kết chéo

Mỗi biểu mẫu đều có phần **"Tài liệu liên quan"** ở cuối file — bạn có thể nhanh chóng chuyển đến biểu mẫu liên quan để tham khảo hoặc cập nhật.

## Quy ước

| Ký hiệu | Ý nghĩa |
|---------|---------|
| `[điền tại đây]` | Thông tin cần được bạn điền vào |
| `[nhóm]` | Tên nhóm Scrum |
| `[dự án]` | Tên dự án |
| `[ngày]` | Ngày tháng |

---

> **Mẹo**: Dùng VS Code hoặc trình soạn thảo Markdown để xem và chỉnh sửa các biểu mẫu một cách trực quan. Sử dụng `Ctrl+Click` vào các đường dẫn để chuyển nhanh giữa các biểu mẫu.
